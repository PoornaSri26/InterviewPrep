# InterviewPrep - InterviewMaster OS

A comprehensive interview preparation platform with AI-powered mock interviews, DSA practice, system design, behavioral questions, and more.

## Features

- **AI Voice Mock Interviews** - Practice with AI-powered interview simulations
- **DSA + LeetCode Sheets** - Practice with company-specific problems and SRS tracking
- **System Design** - 1000+ system design examples with architecture diagrams
- **Flashcards** - 20000+ flashcards with spaced repetition
- **Behavioral/STAR Studio** - Prepare STAR stories for behavioral interviews
- **Company Prep** - Company-specific interview insights
- **Roadmap & Daily Challenges** - Structured learning paths

## Tech Stack

- React 19 + TypeScript
- Vite
- Modern UI with glassmorphism design

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
